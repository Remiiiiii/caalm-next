# Conventions (Cursor adaptation of Emotix founder plugin)

## founder/ folder (optional workshop artifacts)

At the repo root, agents may read/write:

- `founder/facts.md` — founder-stated facts only (stage, metrics, raise). Gitignored.
- `founder/pricing-strategy.md` — latest pricing workshop output (may be committed as reference).

If a file is missing, continue. User input overrides saved facts.

## External claims

Competitor prices need a source link and check date. Use "Estimate:" or "Not found" when unsure.

## CAALM product facts

Always read [caalm-shipped-pricing-context.md](../founder-pricing-strategy/caalm-shipped-pricing-context.md) before pricing CAALM tiers. Do not invent shipped features or limits.

## Writing

Plain words, real dollar amounts, no em dashes (U+2014/U+2013). Stay under 1500 words unless the user asks for more.
