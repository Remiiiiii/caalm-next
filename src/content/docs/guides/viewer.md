Viewers are not “lesser users.” You are often the early-warning system.

## Home base

`/dashboard/viewer` — executive-style visibility with read-oriented constraints.

## How to create value

1. Watch expiry and risk widgets daily.
2. When something looks wrong, identify the owner from the record.
3. Escalate with specifics: record name, date, what seems off, screenshot if needed.
4. Use audits/analytics (when permitted) to prepare questions for standups.

## What “read-only” means in practice

- You can open and inspect many screens
- Upload / assign / approve actions may be hidden or locked
- Some nav items appear elevated with a lock icon

## Do not

- Borrow someone else’s login to “just edit quickly”
- Ignore a bad date because you cannot fix it yourself — escalate it
- Assume lack of edit rights means lack of responsibility

If you need limited write access for a project, request a precise permission — not a full admin role.
