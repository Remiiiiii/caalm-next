The files library is where evidence lives.

## Libraries

Typed routes under the app (documents, images, media, others, uploads) give people a predictable place to put supporting artifacts. Contracts also have dedicated handling in the product navigation model.

## Why this matters

Auditors and funders do not accept “it’s in someone’s email.” CAALM’s value depends on files being:

- Findable
- Permissioned
- Tied to the agreement they support
- Retained intentionally

## Sharing

Shared file links/pages (`/shared/files/[fileId]`) exist for controlled sharing workflows. Treat share scope as a security decision.

## Storage awareness

IT and admin surfaces can expose storage usage. Large media dumps without retention policy become an expensive junk drawer.

## Practical rules

1. Name files for humans (`2026-07-facility-license-renewal.pdf`)
2. Prefer attaching evidence to the record workflow when available
3. Do not upload secrets into broadly shared folders
4. Remove or archive obsolete evidence according to policy — do not hoard conflicting versions without labels
