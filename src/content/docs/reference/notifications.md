Notifications are how CAALM taps you on the shoulder.

## In-app Notification Center

- Open from the header bell
- Filter and mark read
- Deep-link into the record/work item
- Reorder / organize when the UI allows — keep high-signal categories visible

## Other channels

Email and SMS are used for selected operational and auth/onboarding flows when configured. Personal settings under `/settings` control much of what you receive.

## Trust rules

1. If alerts are wrong, fix source dates/owners — do not only mute
2. If alerts are noisy, mute surgically
3. If alerts are silent, verify settings + ownership + org configuration

See troubleshooting: [Missed renewals](/docs/troubleshooting/missed-renewals).
