Settings is where each user makes CAALM safe and tolerable.

## Personal settings (`/settings`)

- Profile details
- Notification preferences
- Two-factor setup
- Access transparency

## View My Access (`/settings/permissions`)

This page is your personal source of truth for roles and permissions. Use it before filing “CAALM is broken” tickets.

## Org-level settings

Organization / system / billing settings are separate admin surfaces and require settings permissions.

If you cannot see billing, you are not broken — you are correctly scoped.
