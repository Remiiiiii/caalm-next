Global search lives at `/search`.

## Use it when

- You remember a vendor or license name but not the path
- A dashboard widget pointed at a problem and you need the record
- You are covering for a teammate and inheritance is unclear

## Tips

- Search the distinctive token (contract number, license id, org name)
- If results are missing, you may lack permission to see the record — that is security, not a bad index
- Prefer opening the record and verifying dates/owners over trusting snippets alone
