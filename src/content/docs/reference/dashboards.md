Dashboards are CAALM’s morning briefing. They are not decorative charts.

## Common dashboard jobs

- Show what is expiring soon
- Show what is waiting on approval
- Show people/invite health (admin views)
- Show news and operational context
- Route you into the queue you own

## By role

See [Roles and home dashboards](/docs/concepts/roles-and-dashboards) for paths. In practice:

- **Executive / Viewer shells** emphasize org risk and overview charts
- **Org Admin** emphasizes operational administration
- **Department Manager** emphasizes division action queues
- **Content Creator** emphasizes publishing metrics
- **IT** emphasizes platform health

## How to read a widget like an operator

1. What decision does this number demand?
2. Who owns the underlying records?
3. What is the next click?
4. If the number is wrong, which metadata field is lying?

## Customization notes

Some widgets and notification layouts can be rearranged (for example notification center ordering). Treat personal layout changes as productivity — not as a substitute for fixing data quality.
