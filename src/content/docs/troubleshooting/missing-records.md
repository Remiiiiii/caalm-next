If a record “vanished,” it is usually hidden — not deleted.

## Check these in order

1. **Search** for a distinctive token
2. **Filters** (status, owner, date, division)
3. **Correct library** (All vs My vs Department)
4. **Permissions** via View My Access (`contracts.view` / `licenses.view`)
5. **Division scope** (managers)
6. **Ownership** (my-contracts only shows your working set)
7. **Ask an admin** to open it with broader access

## Admin verification

- Does the document exist in the database/UI for Super Admin?
- Was it filed under a different division?
- Was it deleted / archived?
- Does the user’s role lack view permission?

## Prevent repeats

- Standardize where records are created
- Require owner + division on intake
- Train people not to upload “temporary” copies into random file buckets without linking the record
