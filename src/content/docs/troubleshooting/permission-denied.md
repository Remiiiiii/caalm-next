title: "Permission denied / locked items"
description: "What locks mean and how to unlock the right way."
section: troubleshooting

---

A lock icon means CAALM recognized the feature and recognized that you are not cleared for it.

## User response

1. Open **View My Access**
2. Identify what you were trying to do in plain language (“approve a license”)
3. Request that capability from an admin
4. Do not borrow an admin login

## Admin response

1. Translate the request into permission keys
2. Grant the minimum role change
3. Confirm separation-of-duties still holds
4. Ask the user to refresh and retry
5. Record why access expanded

## Elevated features

Some nav items are intentionally elevated (approvals, billing, system). Seeing a lock can be correct forever for that user — not every request should be granted.
