## Tasks (Who / What / Where / Why / When / How)

### 1.1 Org filter on view-all contract lists

- **Who:** Every customer org admin and legal ops user
- **What:** Contract list queries always include the signed-in workspace id, even for view-all roles
- **Where:** src/lib/rbac/data-scope.ts, contracts list APIs
- **Why:** Without this, one tenant could see another tenant's contracts in a shared database
- **When:** First PRD product section — before widening sales to multi-tenant hosting
- **How:** Pass orgId into buildContractQueries for all_org mode; add tests with two orgs in one database

**Done when**
- User in Org A with view-all never sees Org B contract rows
- Department and own scopes still work unchanged

### 1.2 Org filter on licenses, files, and invites

- **Who:** Operations teams managing licenses and uploads
- **What:** List and count APIs for licenses, files, and pending invites always scope to the caller's org
- **Where:** planLimits counters, file list routes, invitation list
- **Why:** Billing meters and limits are wrong if counts bleed across tenants
- **When:** Same PR batch as 1.1 when possible
- **How:** Audit each listRows path for Query.equal orgId; fix any missing filter

**Done when**
- Cross-org read by id returns 404 or 403
- Usage meters match org-scoped counts only

### 1.3 Automated two-org regression tests

- **When:** Before marking section 1 complete
- **How:** Fixture org A/B users; assert list totals and forbidden cross-reads

**Done when**
