## Tasks (Who / What / Where / Why / When / How)

### 11.1 create_ticket

- **Who:** Users who can create tickets
- **What:** Create, open, and list tickets
- **Where:** wrap tickets API
- **Why:** Intake and triage are common
- **When:** Tickets batch
- **How:** Creating confirms and audits; list/get is org-scoped

**Done when**
- create_ticket confirms and audits; get_ticket/list_tickets are org-scoped; gated by the ticket permission
- No cross-org ticket reads

### 11.2 assign_ticket

- **Who:** Users with tickets.assign / tickets.resolve
- **What:** Assign, resolve, or comment on a ticket
- **Where:** wrap ticket workflow API
- **Why:** Workflow actions move tickets
- **When:** Tickets batch
- **How:** Confirm; audit; permissioned per action

**Done when**
- assign_ticket is registered in the assistant tool registry and only offered when the user has tickets.assign / tickets.resolve
- Mutating call shows a confirm step and writes an audit entry (who/what/when/tenant) on success; no role-name bypass

### 11.3 search_runbooks

- **Who:** IT users who can view runbooks
- **What:** Search runbooks and return a runbook step
- **Where:** wrap runbooks read
- **Why:** Runbooks guide IT response
- **When:** Tickets batch
- **How:** Read-only; org-scoped

**Done when**
- search_runbooks is registered and gated by the IT runbooks view permission; results are scoped to the caller's org
- Returns a clear message (not a crash) when the user lacks the IT runbooks view permission or no data matches

### 11.4 get_system_health

- **Who:** IT users with the IT view permission
- **What:** Return deployment list / system-health reads only (no control actions)
- **Where:** wrap read-only IT status
- **Why:** Status visibility without dangerous control
- **When:** Tickets batch
- **How:** Read-only; never expose force-delete, manage-schema, or API-key tools to the chat agent

**Done when**
- get_system_health is read-only and gated by the IT view permission
- Platform force-delete, manage-schema, and API-key management are NOT exposed as assistant tools
