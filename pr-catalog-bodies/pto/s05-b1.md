### 5.1 search_clauses

- **Who:** Users who can view clauses
- **What:** Find approved clause language and return one clause
- **Where:** wrap clause library read
- **Why:** Drafting reuses approved language
- **When:** Clauses batch
- **How:** Read-only; org-scoped

**Done when**
- search_clauses is registered and gated by the clauses view permission; results are scoped to the caller's org
- Returns a clear message (not a crash) when the user lacks the clauses view permission or no data matches

- **Who:** Users with clauses.create
- **What:** Create, update, or retire a clause in the library
- **Where:** wrap clause CRUD
- **Why:** Curation keeps the library current
- **When:** Clauses batch
- **How:** Confirm; audit; org-scoped

**Done when**
- create_clause is registered in the assistant tool registry and only offered when the user has clauses.create / clauses.edit

- **What:** Drop an approved clause into an active draft or template
- **Where:** wrap draft editor insert
- **Why:** Connects library to drafting
- **When:** Clauses batch
- **How:** Confirm; audit the edit

**Done when**
- insert_clause_into_draft is registered in the assistant tool registry and only offered when the user has contracts.edit

**Done when**
