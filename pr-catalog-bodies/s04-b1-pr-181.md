## Tasks (Who / What / Where / Why / When / How)

### 4.1 Real audit data by default in production

- **Who:** Compliance officers and execs
- **What:** Production uses live audit log data unless an admin explicitly enables demo mode
- **Where:** src/lib/audits/mock-data.ts, env flags
- **Why:** Mock KPIs in a sales demo are fine; mock in production erodes trust
- **When:** After sign-in section
- **How:** Default USE_AUDIT_MOCK_DATA false outside development; show DEMO badge if ever on

**Done when**
- Production config test fails if mock defaults true
- Audit log page still loads real rows

### 4.2 Label or replace sample analytics widgets

- **Who:** Dashboard users
- **What:** Every chart is either fed by real queries or clearly labeled Sample data
- **Where:** analytics components, org charts
- **Why:** Executives make decisions on numbers; fake charts are a liability
- **When:** After 4.1
- **How:** Inventory widgets; wire or badge; remove dead mock imports

**Done when**
- Inventory test lists each widget as live or sample
- No silent mock series on executive dashboards

### 4.3 Fix or hide the unified analytics API for customers

- **Who:** Internal analytics page consumers
- **What:** Unified analytics either respects permissions and org scope or is removed from customer navigation
- **Where:** /api/analytics/unified, analytics page
- **Why:** This route was flagged as over-broad in the assessment
- **When:** Pairs with section 2.2
- **How:** After gating, verify response shape; or feature-flag off until fixed

**Done when**
- Unified route not callable without permission
- UI does not call unified until green tests exist

### 4.4 Compliance tab honesty

- **Who:** Audit and compliance viewers
- **What:** Compliance domains that still use blended mock data show a plain notice at the top
- **Where:** audits compliance pages, merge-live-data helpers
- **Why:** Mixed live and mock without a label feels like bait-and-switch
- **When:** End of section 4
- **How:** Short banner: which metrics are live vs illustrative

**Done when**
- Banner visible when mock merge is active
- Live audit log section unaffected
