## Tasks (Who / What / Where / Why / When / How)

### 2.1 Protect file upload and download

- **Who:** Authenticated staff uploading contracts and licenses
- **What:** File upload, download, and share routes require the same permissions as viewing or editing the underlying record
- **Where:** src/app/api/files/*, file.actions
- **Why:** Files are the crown jewels; open routes are the fastest path to data loss
- **When:** After section 1 isolation
- **How:** requirePermission on each method; return 401/403 tests; remove routes from authz baseline when gated

**Done when**
- Anonymous and wrong-permission callers get 401 or 403
- Baseline entry count drops for listed file routes

### 2.2 Protect analytics and reporting APIs

- **Who:** Leaders viewing dashboards
- **What:** Analytics unified, calendar, department, and admin routes require analytics or contract view permissions and org scope
- **Where:** src/app/api/analytics/*
- **Why:** Unified route today can over-read without a permission check
- **When:** After 2.1
- **How:** Gate each route; shrink baseline; add negative tests

**Done when**
- /api/analytics/unified returns 403 without permission
- No cross-org aggregates in responses

### 2.3 Protect assistant and legacy AI routes

- **Who:** Staff using in-app assistant and AI tools
- **What:** Assistant chat/execute and legacy ai-analyze routes require authentication and appropriate AI or contract permissions
- **Where:** src/app/api/assistant/*, ai-analyze, ai-contract-type-suggest
- **Why:** Unguarded AI routes burn cost and can leak document snippets
- **When:** After 2.2
- **How:** Same requirePermission pattern as newer extract routes

**Done when**
- Unguarded baseline no longer lists assistant/*
- Positive and negative authz tests pass

### 2.4 Retire duplicate contract pipeline routes

- **Who:** Engineering
- **What:** Either gate or remove legacy v1 and duplicate draft/extract routes so one blessed path remains
- **Where:** src/app/api/v1/contracts/*, contracts/drafts*, extract-data duplicates
- **Why:** Two paths mean one stays unguarded when the other is fixed
- **When:** Mid section 2
- **How:** Inventory callers; migrate UI to gated routes; delete or gate stragglers

**Done when**
- Baseline shrinks for retired paths
- No production UI calls an unguarded duplicate

### 2.5 CI ratchet on the unguarded list

- **Who:** CI and every PR author
- **What:** Automated test fails if api-authz-baseline.json grows; celebrate when it shrinks
- **Where:** tests for test:api-authz, baseline json
- **Why:** Grandfather list was meant to ratchet down; without CI it rots
- **When:** End of section 2
- **How:** Compare baseline length in CI; document allowlist additions in PR

**Done when**
- PR that adds unguarded routes fails CI unless baseline intentionally updated with review
- Section PR documents before/after baseline count
