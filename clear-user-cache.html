🧹 Clear User Cache

This page will help you clear all cached user data to fix role routing issues.

What will be cleared:

  • localStorage.cached_user - Cached user profile
  • localStorage.session - Session data
  • sessionStorage - All temporary data
  • All cookies for this domain

Manual Steps (if needed):

  1. Press F12 to open Developer Tools
  2. Go to the Application tab
  3. Under Storage, click Clear site data
  4. Press Ctrl + Shift + R (hard refresh)
  5. Sign in again
